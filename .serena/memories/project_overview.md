Laravel 12 PHP application named OpenDeviceManager. Uses traditional Laravel skeleton with `bootstrap/app.php` binding `App\\Exceptions\\Handler` rather than the newer Laravel 11+ bootstrap exception closure style. Main areas: `app/`, `routes/`, `resources/`, `tests/`, `docs/`, `config/`, `database/`. Custom exception hierarchy under `app/Exceptions` with domain and infrastructure subfolders, plus ADR docs under `docs/adr/`. Frontend/build tooling includes Vite, Tailwind, TypeScript, and pnpm lockfile.
